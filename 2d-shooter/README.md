# Chrome Ember

A top-down pixel-art arena shooter built with PyGameKit.

## Controls

- `WASD`: move
- Mouse: aim
- Hold left mouse: fire
- `Space`: dash
- `1`, `2`, `3` or click: choose a wave upgrade
- `R`: restart after defeat
- `Esc`: quit

Run from the toolkit root:

```bash
python3 "2d-shooter/main.py"
```
